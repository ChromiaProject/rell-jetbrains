# Updating Rell GrammarThis guide walks you through updating the grammar when upgrading to a new Rell version.## PrerequisitesInstall the following IntelliJ plugins:- [Plugin DevKit](https://plugins.jetbrains.com/plugin/22851-plugin-devkit)- [Grammar-Kit](https://plugins.jetbrains.com/plugin/6606-grammar-kit)## Step 1: Update the Rell VersionUpdate the Rell version in both:- `bnf-grammar-generator/gradle.properties`- `gradle.properties`## Step 2: Update the Grammar File1. Open `src/main/kotlin/net/postchain/rellide/jetbrains/language/Rell.bnf`2. Update the grammar definitions. For reference:    - Check the `rell-toolbox` project's git history for the `Rell.g4` file to see how grammar changed in this Rell version    - Alternatively, auto-generate a starting point by running `bnf-grammar-generator/src/main/kotlin/net/postchain/rellide/jetbrains/grammar/BnfGrammar.kt`   ⚠️ **Important:** Don't trust auto-generated output completely. Always analyze and verify grammar changes manually.## Step 3: Update the Lexer (If Needed)**Only do this if you added new tokens** (found in the `tokens=[]` list near the top of `Rell.bnf`):1. Right-click `Rell.bnf` → Select **Generate JFlex Lexer**2. Review the generated `_RellLexer.flex` file3. Manually apply the relevant changes to the source-controlled `__RellLexer.flex` file⚠️ **Note:** The generated file is a reference, not the final version. Cherry-pick the changes you need.## Step 4: Generate Parser and Lexer Code1. Right-click `Rell.bnf` → Select **Generate Parser Code**2. Right-click `__RellLexer.flex` → Select **Run JFlex Generator**## Step 5: Test Your ChangesRun the test suite to verify everything works:- Execute tests in `src/test/kotlin/net/postchain/rellide/jetbrains/RellParsingTest.kt`
