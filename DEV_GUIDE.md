## 🔧 Development Setup

### Prerequisites

- **IntelliJ IDEA Ultimate or Community Edition** (latest stable version)
- **JDK 21+** (recommended for plugin development)

### Setting Up Development Environment
**📦 Build the Plugin**
```sh
  ./gradlew buildPlugin
```

**🚀 Run the Plugin**
```sh
  ./gradlew runIde
```
